# 微信订阅消息

## 范围

站内消息是可靠主通道，微信订阅消息是可选提醒。用户拒绝或微信发送失败均不得阻塞任务、提交和审核业务。

支持的偏好：

- 任务分配/更新提醒
- 审核结果提醒
- 截止时间提醒

## 配置来源

模板 ID 以后端配置为主；前端环境变量只作为开发备用。模板 ID、AppID 可以公开，但 AppSecret 和 Access Token 只保存在服务端。

## 授权流程

1. 用户在“消息设置”主动开启某类提醒。
2. 小程序调用 `uni.requestSubscribeMessage` 请求对应模板。
3. 接受、拒绝、ban 和异常结果均同步为本地展示状态；服务端保存业务偏好。
4. 后端在站内消息落库后尝试发送订阅消息，失败记录日志并可重试，不重复创建站内消息。

## 验证声明

Mock Provider 只验证调用和模板映射。没有真实 AppID、模板与合法域名时，真实发送结果必须标记为 `UNAVAILABLE`，不得写成“已验证”。
