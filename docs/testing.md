# 测试指南

## 本地命令

```bash
npm run type-check
npm run test
npm run build:h5
npm run build:mp-weixin
```

`npm run test` 使用 Vitest 执行纯领域与格式化测试。测试不得依赖当前真实时间而导致跨天不稳定；涉及截止时间时应冻结系统时间。

## 测试层次

- 单元测试：状态派生、徽标、格式化、DTO 映射、错误映射、刷新锁、上传状态机。
- 组件测试：加载、空、错误、分页失败、提交禁用与重试状态。
- Mock H5 E2E：从登录到 V2 审核通过的完整演示闭环。
- 真实后端 E2E：登录、授权范围、上传下载、驳回重交和统计联动。
- 微信开发者工具：导航、安全区、授权、上传、下载、文档打开和机型布局。

## Golden Path

1. 张老师登录并查看已分配任务。
2. 下载模板，上传材料并提交 V1。
3. Web 审核驳回，教师收到消息。
4. 教师查看意见并提交 V2。
5. Web 审核通过。
6. Assignment、提交历史、未读消息和 Dashboard 同步更新。

## 负向用例

- 教师不能查看他人任务、提交和文件。
- 非法/超限文件、过期令牌、重复审核和重复提交被拒绝。
- 审核人不能审核自己的提交。
- 分页失败保留已有数据；上传失败不能显示提交成功。

## 证据记录

交付报告写明命令、日期和实际结果。未运行使用 `NOT_TESTED`；环境不具备使用 `UNAVAILABLE`；不得用历史日志或 Mock 结果替代真实验证。
